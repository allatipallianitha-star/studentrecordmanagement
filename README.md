Student Record Management System

Project Description

A simple Student Record Management System developed using Python and SQLite. It helps users manage student information through a command-line interface.

Features

- Add a new student
- View all student records
- Search for a student by ID
- Update student details
- Delete student records
- Validate GPA between 0 and 10
- Handle duplicate student IDs and email addresses

Technologies Used

- Python
- SQLite
- SQL

Project Files

- "main.py" – Runs the menu-driven application.
- "database.py" – Handles database operations.
- "students.db" – SQLite database created when the application runs.
- ".gitignore" – Specifies files Git should ignore.

How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

python main.py

5. Follow the menu options to manage student records.
